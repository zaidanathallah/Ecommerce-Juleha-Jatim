# Ecommerce-Juleha-Jatim
Platform E-commerce dan Marketplace resmi untuk anggota Juru Sembelih Halal (Juleha) Jawa Timur. 

Sistem ini terintegrasi langsung dengan database keanggotaan pusat untuk memastikan hanya anggota tervalidasi yang dapat bertransaksi. Dilengkapi dengan infrastruktur margin berjenjang untuk pemasukan kas daerah/provinsi, pembayaran instan via DOKU, dan logistik otomatis via Biteship.
